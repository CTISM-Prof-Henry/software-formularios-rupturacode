# Cadastro de Setores

## Objetivo

Cadastrar os setores responsáveis pelos riscos.

## Passos

1. Acesse o menu **Setores**.
2. Clique em **Novo Setor**.
3. Informe:
   - Nome do setor;
   - Descrição;
   - Responsável.
4. Clique em **Salvar**.

## Resultado Esperado

O setor ficará disponível para associação aos riscos.
