# Monitoramento dos Riscos

## Objetivo

Acompanhar a evolução e o ciclo de vida dos riscos cadastrados.

## Funcionalidades Disponíveis

- Atualização de status;
- Consulta do histórico de alterações;
- Registro de observações;
- Controle de prazos.

## Resultado Esperado

O monitoramento contínuo garante maior controle sobre os riscos institucionais, permitindo respostas rápidas e decisões baseadas no histórico de cada caso.
