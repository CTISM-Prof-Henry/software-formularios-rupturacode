# Avaliação de Riscos

## Objetivo

Classificar os riscos cadastrados conforme sua gravidade para facilitar a priorização.

## Critérios de Avaliação

### Probabilidade

Define a chance de o risco se concretizar:

- Baixa;
- Média;
- Alta.

### Impacto

Define a gravidade das consequências caso o risco ocorra:

- Baixo;
- Médio;
- Alto.

## Classificação Automática

O sistema calcula automaticamente o nível de risco final com base na combinação dos valores informados nos campos de Probabilidade e Impacto. O usuário não precisa realizar nenhum cálculo manual.

## Resultado Esperado

O risco receberá uma classificação consolidada adequada, destacando os itens mais críticos para priorização na tela de listagem.
