# Relatórios

## Objetivo

Gerar relatórios gerenciais para auxiliar na análise e acompanhamento dos riscos institucionais.

## Tipos de Relatórios

- Riscos por setor;
- Riscos por categoria;
- Riscos críticos;
- Planos de tratamento em andamento.

## Passos para Gerar um Relatório

1. Acesse o menu **Relatórios**.
2. Selecione os filtros desejados.
3. Clique em **Gerar Relatório**.

## Resultado Esperado

O relatório será exibido na tela ou disponibilizado para exportação, conforme a funcionalidade selecionada.
