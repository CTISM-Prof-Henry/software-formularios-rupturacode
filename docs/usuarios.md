# Gerenciamento de Usuários

## Objetivo

Administrar os acessos ao sistema, garantindo maior controle e segurança sobre as funcionalidades disponíveis para cada usuário.

## Funcionalidades

- Cadastrar usuário;
- Editar usuário;
- Excluir usuário;
- Definir permissões.

## Resultado Esperado

O sistema permite o controle seguro dos acessos, garantindo que cada usuário possua apenas as permissões adequadas ao seu perfil.
