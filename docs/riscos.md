# Cadastro de Riscos

## Objetivo

Registrar um novo risco no sistema.

## Passos

1. Acesse o menu **Riscos**.
2. Clique no botão **Cadastrar Risco**.
3. Preencha os seguintes campos:
   - Título do risco;
   - Descrição;
   - Categoria;
   - Setor responsável;
   - Probabilidade;
   - Impacto.
4. Clique em **Salvar**.

## Resultado Esperado

O risco será registrado no sistema e ficará disponível para acompanhamento na listagem principal.
