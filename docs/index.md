# Sistema de Gerenciamento de Riscos da UFSM

**Desenvolvido por:** Equipe RupturaCode

## Objetivo do Sistema

O Sistema de Gerenciamento de Riscos da UFSM foi desenvolvido para auxiliar na identificação, avaliação, monitoramento e tratamento de riscos institucionais, proporcionando maior controle e transparência nos processos de gestão.

## Público-Alvo

- Gestores;
- Servidores responsáveis pelos setores;
- Administradores do sistema;
- Equipes de controle interno.

Utilize o menu lateral para acessar os módulos e funcionalidades do sistema.
